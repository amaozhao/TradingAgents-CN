## 🤖 什么是大语言模型？

### 定义

**大语言模型**是一种基于深度学习的自然语言处理（NLP）模型，通过在海量文本数据上进行训练，学习语言的模式和规律，从而能够理解和生成人类语言。

简单来说，LLM 像一个“读过大量文本、会根据上下文组织回答”的 AI 助手。它可以：
- 📖 理解你的问题
- 💬 用自然语言回答
- 📝 生成各种文本内容
- 🔍 分析和总结信息
- 🧰 按要求调用外部工具，读取行情、财报、新闻等实时数据

### 为什么叫"大"语言模型？

"大"主要体现在三个方面：

1. **参数规模大**
   - 早期代表模型如 GPT-3 公开披露为 1750 亿参数
   - 现在的主流模型有闭源、开源、MoE（混合专家）等多种形态，很多模型不再公开精确参数量
   - 参数规模只是一项参考，最终效果还取决于训练数据、推理能力、工具调用稳定性和上下文长度

2. **训练数据大**
   - 训练数据通常包含数TB的文本
   - 涵盖书籍、网页、论文等多种来源
   - 数据越多，模型的知识越丰富

3. **计算资源大**
   - 需要数千个GPU进行训练
   - 训练时间可能长达数月
   - 成本可能达到数百万美元

> 注意：不要只根据“参数量”判断模型好坏。股票分析更关心事实准确性、工具调用成功率、长文档处理能力、成本和响应速度。

## 🔧 LLM的工作原理

### 1. Transformer架构

大语言模型基于**Transformer**架构，这是一种专门为处理序列数据（如文本）设计的神经网络结构。

```
输入文本 → Token化 → Embedding → Transformer层 → 输出预测
```

**关键组件**：
- **Self-Attention机制**：让模型能够关注文本中的重要部分
- **多头注意力**：从多个角度理解文本
- **前馈神经网络**：进行复杂的特征转换

### 2. 预训练与微调

LLM的训练分为两个阶段：

**阶段1：预训练（Pre-training）**
- 在海量无标注文本上训练
- 学习语言的基本规律和知识
- 目标：预测下一个词（Next Token Prediction）

**阶段2：微调（Fine-tuning）**
- 在特定任务的数据上进一步训练
- 适应特定领域或任务
- 例如：针对股票分析进行微调

### 3. 提示学习与工具调用

现代LLM通过**提示词（Prompt）**来理解任务：

```
提示词示例：
"请分析以下股票的研究价值：
股票代码：000001
行业：银行
市盈率：5.2
市净率：0.6
..."
```

模型会根据提示词的内容和格式，生成相应的分析报告。

在股票分析系统里，LLM 不应该凭记忆回答“最新股价、PE、公告、新闻”。更可靠的流程是：

```
用户问题 → LLM理解任务 → 调用行情/财报/新闻工具 → 汇总数据 → 生成分析
```

这也是 AGENTrader 使用多智能体和数据工具的原因：让模型负责理解、推理和表达，让数据源负责提供实时事实。

## ⭐ LLM的核心特点

### 1. 通用性（Generalization）

- ✅ 可以处理多种自然语言任务
- ✅ 无需为每个任务单独训练
- ✅ 通过提示词即可切换任务

**示例**：
- 文本生成：写文章、写代码
- 文本理解：问答、摘要
- 文本分析：情感分析、实体识别

### 2. 上下文学习（In-Context Learning）

- ✅ 可以从示例中学习
- ✅ 无需更新模型参数
- ✅ 通过Few-shot提示即可适应新任务

**示例**：
```
示例1：股票代码：600519，行业：白酒，风险等级：中等
示例2：股票代码：000858，行业：白酒，风险等级：偏高
现在分析：股票代码：000568，行业：白酒，风险等级：？
```

### 3. 涌现能力（Emergent Abilities）

当模型规模达到一定程度时，会出现一些意想不到的能力：

- 🎯 复杂推理能力
- 🎯 代码生成能力
- 🎯 多步骤问题解决
- 🎯 创造性思维

### 4. 知识丰富，但不是实时数据库

LLM在训练过程中学习了大量知识：

- 📚 通用知识：历史、地理、科学
- 💼 专业知识：金融、医学、法律
- 🌍 多语言能力：支持多种语言

但 LLM 的“内置知识”通常来自训练数据，可能存在截止日期；即使模型支持联网或工具调用，也要看当前系统是否真的接入了对应数据源。因此，在投资研究场景里，关键数字必须来自行情、财报、公告、新闻等可追溯来源。

### 5. 多模态与长上下文

新一代模型通常还支持更长上下文，部分模型支持图片、PDF、表格等多模态输入。这些能力适合处理年报、公告、研报截图和长篇新闻，但仍然需要注意：

- 长上下文不等于不会遗漏重点
- PDF/表格解析可能出错
- 图片和截图里的数字仍需交叉验证
- 成本会随输入长度明显增加

## 📊 LLM在股票分析中的应用

### 1. 信息提取与整合

LLM可以从多个来源提取和整合信息，但这些信息应由外部数据源提供，而不是让模型凭记忆编造：

- 📰 新闻报道
- 📊 财务报表
- 💬 社交媒体
- 📈 技术指标

### 2. 多维度分析

LLM可以从多个角度组织股票分析：

- **基本面分析**：财务指标、行业地位
- **技术面分析**：价格走势、技术指标
- **情绪分析**：市场情绪、投资者情绪

### 3. 生成分析报告

LLM可以生成结构化的分析报告，并把不同智能体的结论整理成可阅读的研究记录：

```markdown
## 股票分析报告

### 基本信息
- 股票代码：000001
- 公司名称：平安银行
- 行业：银行

### 综合评价
基于当前数据和关键假设...

### 风险提示
需要注意以下风险因素...
```

## 💡 总结

### 关键要点

1. **LLM是什么**：基于深度学习的大规模语言模型
2. **核心技术**：Transformer架构、预训练与微调
3. **主要特点**：通用性、上下文学习、工具调用、长上下文
4. **应用价值**：信息整合、多维分析、报告生成
5. **关键边界**：实时数据必须来自工具和数据源，不能只相信模型记忆

## ❓ 常见问题

**Q: LLM真的"理解"语言吗？**

A: 这是一个哲学问题。LLM通过统计模式学习语言，能够生成合理的回答，但是否真正"理解"语言的含义仍有争议。

**Q: LLM的回答总是正确的吗？**

A: 不是。LLM可能会产生"幻觉"（生成不准确的信息），特别是在处理需要实时数据、精确数字或专业结论的问题时。股票分析里要重点核验价格、财务指标、公告日期、新闻来源和模型生成的计算过程。

**Q: 如何选择合适的LLM？**

A: 需要考虑多个因素：任务需求、成本预算、响应速度、准确性等。详见[模型选择指南](../03-model-selection/model-comparison.md)。
